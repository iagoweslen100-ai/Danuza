# Danuza Thiali - Site Profissional (Pronto para cPanel)

Arquivos prontos para publicação em hospedagem cPanel / Apache / LiteSpeed.

## Como subir no cPanel:
1. Baixe o ZIP deste repositório (botão verde **Code** -> **Download ZIP**) ou baixe o zip direto nas Releases.
2. Acesse seu cPanel e vá em **Gerenciador de Arquivos** (File Manager).
3. Abra a pasta `public_html` (ou o diretório raiz do seu domínio).
4. Faça o upload do arquivo `.zip` e clique em **Extrair** (Extract).
5. Certifique-se de que o arquivo `index.html` e a pasta `assets/` fiquem diretamente dentro de `public_html`.
6. Pronto! O site já estará no ar com rotas limpas, SEO e WhatsApp configurado.
